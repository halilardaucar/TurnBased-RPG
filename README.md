C++ Console Turn-Based RPG

This project is a turn-based console RPG prototype developed to practice Object-Oriented Programming (OOP) concepts (Classes, Objects, Encapsulation) in C++.

Current Features
* Encapsulation: Character stats (health, armor, damage) are protected from external interference using `private` access modifiers.
* Knight Class: Implemented armor/damage reduction, randomized critical hit calculations, and health potion mechanics.
* State/Flag Management: Created an instant "Attack Potion" logic that buffs only the next consecutive attack when used.

Planned Features
* Integration of Mage and Tank classes.
* Implementation of Enemy entities and the core combat Game Loop.
* Map-based progression and basic Skill Tree integration.

Development Environment
* Language: C++
* IDE: Visual Studio
